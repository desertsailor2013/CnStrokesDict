## 一、版本概述

### 1.1 版本目标
在V1.1基础上，扩展高中词库、成语词典，增强听写功能，提升学习体验。

### 1.2 核心特性
- 高中词库：10-12年级词语（约1200词）
- 成语词典：常用成语（约5000条）
- 语音识别听写：用语音输入替代手动输入
- 学习进度统计：记录学习时长、正确率

### 1.3 版本号
- 版本号：1.2.0
- 最低支持：Android 8.0 (API 26)

## 四、语音识别听写

### 4.1 功能设计

#### 4.1.1 识别模式
- 单词识别：识别单个词语
- 连续识别：连续识别多个词语
- 对比模式：显示识别结果与正确答案对比

#### 4.1.2 识别流程
1. 播放词语发音
2. 用户语音输入
3. 识别用户语音
4. 对比正确答案
5. 标记正确/错误

### 4.2 技术实现

#### 4.2.1 语音识别集成
```kotlin
class SpeechRecognizerManager(context: Context) {
    private var recognizer: SpeechRecognizer? = null
    
    fun init() {
        recognizer = SpeechRecognizer.createSpeechRecognizer(context)
        val listener = object : RecognitionListener {
            override fun onResults(results: Bundle?) {
                val matches = results?.getStringArrayList(SpeechRecognizer.RESULTS_RECOGNITION)
                val bestMatch = matches?.firstOrNull()
                // 处理识别结果
            }
            // 其他回调方法
        }
        recognizer?.setRecognitionListener(listener)
    }
    
    fun startListening() {
        val intent = Intent(RecognizerIntent.ACTION_RECOGNIZE_SPEECH).apply {
            putExtra(RecognizerIntent.EXTRA_LANGUAGE_MODEL, RecognizerIntent.LANGUAGE_MODEL_FREE_FORM)
            putExtra(RecognizerIntent.EXTRA_LANGUAGE, "zh-CN")
        }
        recognizer?.startListening(intent)
    }
    
    fun stopListening() {
        recognizer?.stopListening()
    }
}
```

#### 4.2.2 听写流程
```kotlin
class VoiceDictationManager {
    private val ttsManager: TtsManager
    private val speechRecognizer: SpeechRecognizerManager
    private val dictationManager: DictationManager
    
    fun startVoiceDictation(words: List<WordEntry>) {
        dictationManager.start(words)
        playNextWord()
    }
    
    private fun playNextWord() {
        val word = dictationManager.next() ?: return
        ttsManager.speak(word.word)
        // 播放完成后开始识别
        speechRecognizer.startListening()
    }
    
    fun onSpeechResult(result: String) {
        val currentWord = dictationManager.getCurrentWord()
        val isCorrect = result == currentWord?.word
        if (isCorrect) {
            dictationManager.markCorrect(currentWord)
        } else {
            dictationManager.markError(currentWord)
        }
        playNextWord()
    }
}
```

## 十、风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| 高中词语数据获取困难 | 词库不完整 | 使用公开数据集+手动补充 |
| 成语数据量大 | 查询慢 | 优化数据库索引+分页加载 |
| 语音识别准确率低 | 听写体验差 | 支持多种识别引擎+手动修正 |
| 存储空间不足 | 无法安装 | 压缩数据+按需下载 |
| 兼容性问题 | 部分设备崩溃 | 充分测试+降级方案 |
