# CnStrokesDict V1 设计方案

## 一、版本目标

**核心目标**：补齐小学1~6年级生字和常用字词，支持教师/学生自扩充词库。

### V1 功能范围

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 小学1-6年级生字库 | P0 | 约2500字，含笔画、释义、部首等 |
| 教材词语表 | P0 | 部编版1-6年级二字/三字词语 |
| 自扩充词库 | P1 | 教师/学生可创建、导入、导出词库 |
| 二维码分享词库 | P1 | 生成二维码分享词库，扫码导入 |
| 纯离线模式 | P0 | 默认模式，内置全部字库 |
| 按需联网模式 | P2 | 查字时自动补充缺失字（V2实现） |

## 二、数据结构设计

### 2.1 数据库表结构

#### characters（单字表）

```sql
CREATE TABLE characters (
    char TEXT PRIMARY KEY,                    -- 汉字（主键）
    pinyin TEXT,                              -- 拼音（多音字用/分隔）
    radical TEXT,                             -- 部首
    radical_strokes INTEGER,                  -- 部首笔画数
    total_strokes INTEGER,                    -- 总笔画数
    shuowen TEXT,                             -- 说文解字
    definitions TEXT,                         -- 释义（JSON数组）
    strokes TEXT,                             -- 笔画SVG数据（JSON数组）
    stroke_hints TEXT,                        -- 笔画提示（JSON数组）
    evolution TEXT,                           -- 字形演进（JSON数组）
    pinyin_word_examples TEXT,                -- 拼音组词示例（JSON数组）
    idioms TEXT,                              -- 成语（JSON数组）
    source TEXT,                              -- 来源：core/grade_1/.../grade_6
    created_at INTEGER DEFAULT 0,
    updated_at INTEGER DEFAULT 0
);

-- FTS5全文搜索索引
CREATE VIRTUAL TABLE characters_fts USING fts5(
    char, pinyin, definitions, shuowen,
    content=characters,
    content_rowid=rowid
);
```

#### words（词语表）

```sql
CREATE TABLE words (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    word TEXT NOT NULL,                       -- 词语（如"春天"）
    pinyin TEXT,                              -- 拼音
    meaning TEXT,                             -- 释义
    example TEXT,                             -- 例句
    word_length INTEGER,                      -- 词语长度（2=二字，3=三字）
    grade INTEGER,                            -- 年级（1-6）
    semester INTEGER,                         -- 学期（1=上，2=下）
    unit INTEGER,                             -- 单元
    lesson INTEGER,                           -- 课序
    package_id INTEGER DEFAULT 0,             -- 词库包ID（0=内置）
    created_at INTEGER DEFAULT 0,
    FOREIGN KEY (package_id) REFERENCES word_packages(id)
);

-- FTS5全文搜索索引
CREATE VIRTUAL TABLE words_fts USING fts5(
    word, pinyin, meaning,
    content=words,
    content_rowid=rowid
);
```

#### word_packages（词库包表）

```sql
CREATE TABLE word_packages (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,                       -- 词库包名称
    description TEXT,                         -- 描述
    author TEXT,                              -- 作者（教师姓名）
    grade INTEGER,                            -- 年级
    semester INTEGER,                         -- 学期
    word_count INTEGER DEFAULT 0,             -- 词语数量
    qr_code_data TEXT,                        -- 二维码内容（JSON）
    file_path TEXT,                           -- 词库文件路径
    is_builtin INTEGER DEFAULT 0,             -- 是否内置（1=内置）
    is_active INTEGER DEFAULT 1,              -- 是否启用
    created_at INTEGER DEFAULT 0,
    updated_at INTEGER DEFAULT 0
);
```

#### user_settings（用户设置表）

```sql
CREATE TABLE user_settings (
    key TEXT PRIMARY KEY,
    value TEXT,
    updated_at INTEGER DEFAULT 0
);
```

## 三、字库分层设计

### 3.1 字库层级

| 字库 | 字数 | 说明 | 存储位置 |
|------|------|------|----------|
| **core** | ~300 | 最常用基础字（一二三、人口手等） | 内置 assets |
| **grade_1** | ~400 | 一年级上下册生字 | 内置 assets |
| **grade_2** | ~750 | 二年级生字 | 内置 assets |
| **grade_3** | ~600 | 三年级生字 | 内置 assets |
| **grade_4** | ~400 | 四年级生字 | 内置 assets |
| **grade_5** | ~200 | 五年级生字 | 内置 assets |
| **grade_6** | ~150 | 六年级生字 | 内置 assets |
| **textbook** | ~15000 | 教材词语（二字/三字） | 内置 assets |
| **custom** | 按需 | 用户自扩充词库 | filesDir |

### 3.2 数据文件结构

```
app/src/main/assets/
├── dictionary/
│   ├── characters.json         # 单字数据（约2500字）
│   ├── textbook_words.json     # 教材词语（约15000词）
│   └── word_packages.json      # 内置词库包定义
└── hanzi_raw/                  # 笔画SVG数据（可选，已合并到characters.json）
```

### 4.3 二维码分享机制

**二维码内容格式**：

```json
{

  "version": "1.0",
  "data": {
    "name": "三年级上册词语表",
    "author": "张老师",
    "grade": 3,
    "semester": 1,
    "wordCount": 156,
    "words": [
      {"word": "早晨", "pinyin": "zǎo chén", "meaning": "清晨"},
      {"word": "穿戴", "pinyin": "chuān dài", "meaning": "穿着佩戴"},
      ...
    ]
  },
  "checksum": "sha256:abcdef1234567890"

```

**分享流程**：

```
教师创建词库
     │
     ▼
点击「分享」
     │
     ├──→ 生成二维码（显示在屏幕）
     │         │
     │         ▼
     │    学生扫码
     │         │
     │         ▼
     │    自动导入词库
     │
     └──→ 导出JSON文件
               │
               ▼
          发送文件给同事
               │
               ▼
          导入词库
```

## 六、批量构建脚本设计

### 6.1 脚本清单

| 脚本 | 功能 | 输入 | 输出 |
|------|------|------|------|
| `fetch_hanzi_data.py` | 获取笔画SVG数据 | 汉字列表 | `hanzi_raw/*.json` |
| `fetch_definitions.py` | 获取释义数据 | 汉字列表 | `definitions.json` |
| `fetch_textbook_words.py` | 获取教材词语 | 年级/学期 | `textbook_words.json` |
| `build_characters.py` | 构建单字JSON | 笔画+释义 | `characters.json` |
| `build_words.py` | 构建词语JSON | 教材词语 | `textbook_words.json` |
| `build_assets.py` | 打包为assets | 所有数据 | `assets/dictionary/` |
| `import_to_db.py` | 导入数据库 | JSON文件 | SQLite数据库 |

### 6.2 数据来源

| 数据类型 | 来源 | 说明 |
|------|------|------|
| 笔画SVG | Hanzi Writer CDN | `https://cdn.jsdelivr.net/npm/hanzi-writer-data@2.0/` |
| 汉字释义 | 自建数据库 | 需要手动整理或从公开数据集获取 |
| 部首信息 | 汉典网/新华字典 | 需要手动整理 |
| 教材词语 | 部编版教材 | 需要手动整理或从教育资源获取 |
| 成语 | 成语词典 | 常用成语数据 |

### 6.3 构建流程

```
1. 准备汉字列表（小学1-6年级生字表）
   │
   ▼
2. 批量获取笔画SVG数据
   │
   ▼
3. 批量获取释义数据
   │
   ▼
4. 构建单字JSON（characters.json）
   │
   ▼
5. 准备教材词语数据
   │
   ▼
6. 构建词语JSON（textbook_words.json）
   │
   ▼
7. 打包为assets
   │
   ▼
8. 导入数据库
```

## 十、风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| 释义数据获取困难 | 字库不完整 | 使用公开数据集+手动补充 |
| 教材词语整理工作量大 | 词语表不全 | 分阶段完成，优先核心年级 |
| APK体积过大 | 用户下载慢 | 优化数据结构，压缩JSON |
| 二维码数据量限制 | 词库分享受限 | 大词库使用文件分享 |
| 数据库迁移复杂 | 升级困难 | 设计合理的迁移脚本 |
